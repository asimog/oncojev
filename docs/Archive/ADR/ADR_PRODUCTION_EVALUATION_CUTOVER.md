Date: 2026-10-04.
Owning documents: [Architecture](../../ARCHITECTURE.md),
[Implementation plan](../../IMPLEMENTATION_PLAN.md), [AGENTS](../../../AGENTS.md).

## Context

Reconciled against HEAD `5f3f4175fb346d8214782439aeae557067a71666` and its existing
uncommitted semantic-search/source fixes. Those edits and scientific records remain
preserved. The user explicitly requested the Final Production Convergence Plan;
this decision reconciles that request rather than adopting its factual assumptions.

Already implemented: `python -m src` reaches `service_from_environment`,
`AutonomousService`, `build_system`, `run_cycle_async`, one Python block/task owner
and fresh block-local Researcher instances. Recovery/reconstruction and immutable
registry bootstrap exist. The runtime does not generally replay old task stores to
start. Legacy wrapper scripts largely delegate to real owners but some prescribe
scientific procedures and read task-era inputs; their classification/removal still

observation, not qualification of a new production basis.

Verified remaining dependencies: `initial_oncolab_index` automatically loads bundled
historical/fixture execution artifacts, and the institution imports their observations
into a fresh store. An isolated current-source copy with those artifacts removed
fails seed construction. Two production qualification consumers import
`src.evals.reference`; that module imports the evaluation harness. Basic service
import without `src/evals` succeeds because some coupling is lazy, but legitimate
reusable-method resolution still imports evaluation code. Generated selection output
also resides in `src/evals/results`, and the wheel packages all of `src`.
The current mechanical checker validates projection/links, not a production/evaluation
import boundary. No new coordinator, memory or registry is justified.

## Decision

Adopt the existing authority architecture and cut over its package/bootstrap boundary:

- `src/` contains production owners only. `evals/` owns comparisons, corpora,
  experimental models/adapters and outputs; tests own explicit contract fixtures.
  Evaluations/tests may invoke production. Production must not import them or resolve
  their corpora/results/historical proof to perform legitimate operations.
- Preserve candidate/scope/application-bound utility proof validation in the existing
  OncoLab qualification owner. Move the shared retention/resolution mechanism out of
  the evaluation module before relocating evaluation-only implementation. Keep its
  exact reviewer, source, scope, repetition and failure checks; do not replace them
  with a passing flag. Shared proof-schema vocabulary has one production owner.
- Bootstrap a new institution only from current curated capability descriptors/routes
  and state generated by that instance. Historical execution observations are not
  static capability definitions or current qualification. Stop automatic historical
  imports; preserve explicit archive reading separately where needed.
- `AutonomousService` remains the operational research entrypoint. Compatibility
  launchers can delegate to it; component/qualification probes remain explicitly
  labelled and cannot become alternate lifecycle/admission authorities.
- Keep research control open-ended. Source-specific typed adapters/contracts may exist
  in Sources/Science/OncoLab, but new compatible capabilities must not require a new
  branch in Director/Researcher control. Existing narrowly supported reusable dispatch
  is not a general evolving capability space and must be completed within its owner.
- Black-box whole-lab evaluation supplies broad direction, availability, configuration
  and budgets to the real production entrypoint, then observes canonical records.
  Scripted component proof remains labelled contract/composition proof.
- Verify replacement behavior before removing superseded scripts, corpora, generated
  outputs and compatibility. Preserve unique scientific evidence and provenance in an
  explicit archive/artifact owner; do not silently merge old state into new production.

Execution and all remaining gates belong only in the implementation plan. Acceptance
of this boundary decision does not qualify the runtime or scientific utility.

## Alternatives

Retain `src/evals` because a qualification resolver imports it: rejected; that makes
production depend on experimental harnesses. Move the resolver with evaluation:
rejected; production qualification is a real existing owner. Copy the resolver:
rejected; creates two qualification authorities. Seed new stores with historical
passing records: rejected; confuses history/fixtures with current qualified execution.
Rewrite the lab as a fixed oncology pipeline or add another orchestrator: rejected;
existing authority boundaries are coherent and the requested goal requires autonomy.
Delete all old evidence immediately: rejected; caller/replacement verification and
preservation must precede removal from the active tree.

## Consequences

Cleaner installation and empty-store behavior; experiment changes no longer import
into the production runtime. Import/caller checks and clean source/wheel probes must
accompany the cutover. Existing application identities, block pins and qualifications
remain historical exact-basis records; a new production basis requires its own proof.
Fresh live continuity, governed capability reuse and deployment verification remain
substantial work. Successful local checks cannot substitute for them.

## Invariants/boundaries affected

Package dependency direction changes; historical bootstrap imports cease. Canonical
SQLite records, Python writes, block lifecycle/deadlines/resources, Director global
scope, Researcher local scope, Jev measurement, Reasoner proposals, deterministic
Science/admission and governed OncoLab acceptance remain owned as before.
Architecture/projection describe delivered behavior, not this undecided future work.
The accepted target boundary is linked there; implementation truth changes only as
its owning plan tasks finish. Missing, failure, unknown and operational closure remain
distinct from biological negatives or scientific resolution.
