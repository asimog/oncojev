# ADR Archive

Historical architecture decision records live here. They are decision history,
not an additional planning/status authority. Rejected proposals authorize no work.

- [Rejected: capability-level planning status and evidence](PLAN_STATUS.md)
- [ADR template](TEMPLATE.md)

Use the template for a concrete decision. Keep the status, reason and consequences
brief; link to the existing owning documents rather than duplicating their plans.
