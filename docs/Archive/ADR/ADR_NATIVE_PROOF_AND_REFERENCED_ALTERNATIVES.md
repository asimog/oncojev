# ADR: Bind local proof to measured execution basis and retain referenced alternatives

Date: 2026-10-02. Owners: [Architecture](../../ARCHITECTURE.md) and
[Implementation Plan](../../IMPLEMENTATION_PLAN.md).

## Context

HEAD `2d10d1d2fe7875690d48f8eecaa929679753d877` plus migrated worktree retained
versioned local boolean controls without current environment binding. The existing
fresh-condition evaluation owner had three conditions. Formal frontier generation
required prior digest items, and memory discarded zero-overlap alternatives.
Representation ownership covered retained-schema gating and a single-file STAR parser.
Source metadata, proposals and execution success already had separate authority.

## Decision

Extend those owners. Qualification retains direct operational observations and one
ordinary-profile receipt atomically, checking the same current code, interpreter,
package bytes, standard library, control binaries/shared libraries, kernel settings,
effective policy and owned paths before and after probes and when consumed.
Testing observations cannot qualify. A changed basis cannot reuse historical proof.

The existing fresh-condition harness adds Jev-only and matched bounded-memory
conditions. Published numerical references and generated adverse contracts remain
label-isolated; scientific utility and independent review stay unsupported where
unmeasured. Candidate utility references its retained comparison and exact scope.

Formal frontiers accept bounded authored questions grounded in a retained mission
and inspected source/capability context. Identities preserve test/population/design
and replication distinctions. Retrieval reserves bounded recent filtered alternatives;
receipts expose that route. Allocation retains original experience and selection
basis. New source/prerequisite observations invalidate stale frontiers. Portfolio
history distinguishes observed prerequisite transitions from scientific resolution.

Fixed scientific transforms validate open mutation/segment schemas, clinical/survival
fields, source-linked selected-gene cohorts and one-to-one case joins. They execute
through the installed-operation governor in live mode. Exact input/output references,
units, missingness and information loss remain stored separately from evidence.

## Alternatives

Another runtime, memory store, ranker, corpus harness or automatic importer would
duplicate existing authority. Treating metadata as data or semantic agreement as
resolution would violate current scientific admission boundaries. Cached native
setup is useful for preparation but cannot supply qualification.

## Consequences

Current-environment consumption adds file hashing cost and fails honestly when
required observations are unavailable. Bounded recent exploration may return
irrelevant alternatives; labelled comparisons report misses and uncertainty.
Supported transforms deliberately reject unknown/compressed/large schemas rather
than guess scientific semantics. Published cases may occur in model pretraining;
held-out splits do not establish independent scientific review or clinical utility.

## Invariants/boundaries affected

The service retains leases, record writes and frozen configuration. Science retains
measurement/admission; Director proposals and retrieval contexts never become evidence.
No historical scientific records are relabelled and no testing importer is added.
Architecture and its reviewed projection own current boundaries; the plan owns gaps.

## Verification

Focused owning tests and retained raw probes/comparisons are reported in TASK_LOG;
full task completion and any missing scientific proof remain in the plan. Native
observations and offline contracts demonstrate different scopes.

## Status

ACCEPTED as the implementation choices within the user's Tasks 1–5 request, with
published cases and the independent-review gap explicitly authorized. Acceptance
does not itself complete qualification or scientific evaluation.
