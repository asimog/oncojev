# ADR: Retain independently resolvable qualification for scoped operations

Date: 2026-10-02. Status: ACCEPTED for the explicitly requested Tasks 6–11 scope.
Acceptance is the architecture decision; implementation and proof are separate.

## Context

Reusable governance has candidate/scope gates but lacks producers and a dispatcher.
Local experiments already acquire immutable software and execute under the shared
process governor. The lung clinical slice exposes a concrete descriptive numeric
need; the installed summary remains the adequate simpler baseline. Qualification
must not promote a method from replay, metadata or hand-authored passing booleans.

## Decision

Science derives a predeclared reference contract from retained pinned upstream
source and licence material. Canonical/changed/invalid comparisons resolve actual
owned candidate outputs, independent upstream invocations and native process
receipts. Numerical tolerances, units, entity semantics, parameters and interpretation
stay explicit. Unsuitable scope and unresolved reference executions fail qualification.

Move the existing external pipeline body into one runtime method shared by normal
tools and qualification. The service still owns heavy leases, software reservations,
consumed bytes, resource receipts and persistence. No alternate executor or store is
introduced. Fresh-environment and utility producers use these same retained inputs
and operational record owners; reusable dispatch resolves an immutable pinned route
and current required proof rather than trusting availability or route declarations.

## Alternatives and consequences

Wrapper-derived expectations cannot establish fidelity. Replays alone cannot
establish independent scientific validity or recoverability. A generic arbitrary
package runner would exceed the supported scientific scope. Qualification remains
narrow, recoverable artifacts consume retained capacity, and later environment/code
changes require current local execution qualification. No new oncology inference or
clinical benefit follows from a descriptive mean. Independently reviewed broader
scientific labels remain unavailable where recorded in the plan.

## Boundaries and verification

Source records, proposals, qualification and operational comparisons never become
scientific evidence. Existing Science validation/admission remains authoritative;
testing results do not qualify or import into ordinary research history. The plan
owns future work and missing proof; TASK_LOG records completed verification only.
Direct native producer runs and focused integrity/owner tests demonstrate different
scopes. Exact outcomes are retained by those owners, not inferred from ADR acceptance.
