## Task 5 — Open-ended ordinary Researcher control

Goal: an ordinary block receives objective/context, then chooses scientific needs,
alternatives, sources, hypotheses/tests, semantic comparisons when useful, valid
operations and truthful handoff. No evaluator supplies its scientific procedure.

Verified gaps: ordinary Researcher instructions embed GDC/STAR/case-paired method
procedures and require method semantic assessment before route choice. The existing
ScientificNeed requires an already-selected representation contract and omits explicit
information/relationship/measurement requirements, constraints and known uncertainty.
The default direction names one disease. These are control/interface assumptions;
current source/scientific adapters and their eligibility/admission guards remain valid.
Fresh bootstrap observation also retained linked-cohort and source-query limitations;
the agent-reported filter defect has not been independently diagnosed.

Bounded feature spec: extend the existing OncoLab ScientificNeed to express a need
before acquisition, with optional later representation binding. Add the requested
information/relationship/measurement requirements, constraints and uncertainty under
its existing byte bounds. Existing IndexReceipt/search-page ownership should retain
need-bound discovery context; method input readiness must remain explicitly unknown
or blocked until actual owned inputs and a representation contract exist. Keep role
instructions generic and obtain method/source-specific procedures from typed
capability contracts. Semantic comparison is optional, never execution permission.
No new planner, registry, scientific operation or persistence authority is required.

Scope/owners: `src/researcher/agent.py`, default human direction, existing OncoLab
methods/receipts and runtime search tools, with owning behavioral tests. Production typed need/capability
interfaces. Express question/estimand, population/scope, required information,
relationships, measurement/design requirements, constraints and known uncertainty.
Remove control-level source/modality/method assumptions, mandatory tool sequences or
fixed candidate/hypothesis quotas; keep scientifically necessary bounded resources.
Current GDC/Xena/modality/method adapters are capabilities, not architectural limits.

Completion proof: generic role/need behavior with multiple compatible capability
contracts, plus black-box observation of autonomous choices in Tasks 11/12. Generated
agent responses are contract fixtures, not independent autonomy/scientific proof.
