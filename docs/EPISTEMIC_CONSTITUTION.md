# Epistemic constitution

1. Science measures reality.
2. Jev measures semantic properties of bounded structured state.
3. Reasoner generates possibilities.
4. Researcher chooses local investigation; Director allocates global scope.
5. Deterministic Python controls lifecycle, evidence admission, and frontier policy.

Hard consequences:

- Only deterministic, provenance-bearing `MeasuredResult`s may become `ScientificEvidence`.
- Jev decision, Reasoner output, Researcher interpretation, generated code, and Dossier are not evidence.
- Missing is not zero; source failure is not biological absence; Jev execution failure is not a negative judgment.
- Keep native semantic probability distributions when pruning or exploration depends on them.
- Local questions and local capabilities never self-promote.
- Ledger history is append-only.

Next-stage consequences (binding on planned H0–H15 changes):

- Director global semantic measurements remain bounded typed context. Jev measures, Python composes the frontier, Director chooses global allocation; local scientific strategy stays Researcher-owned.
- Global hypotheses, contradictions, cross-block relation candidates, program reviews and capability gaps are research context, not evidence. Apparent contradiction preserves both original findings; semantic resolution alone cannot settle a scientific claim.
- BlockDelta is deterministically reference-linked to admitted/stored records. It cannot invent scientific negatives, uncertainty resolution or unsupported conclusions.
- A program pause or completed run never proves mission success. Missing capabilities/inputs, operational failures and exhausted directions retain their own truthful outcomes.
- Immutable OncoLab revisions preserve historical capability context. External listings, public repositories, installation, execution, suitability, validation and reusability remain separate facts. Jev cannot mutate the registry or grant an execution route.
- Promotion requires explicit versioned Python governance, scoped validation, replayable software/input/dependency identity and measured utility. Code-requiring capability changes become engineering proposals; no agent modifies live production source or admission policy.
- Coder scratch and a dependency-isolated venv are not evidence authorities. Science alone validates and explicitly admits controlled/reproducible measurements. Actual confinement must be verified independently from dependency isolation.
- The database remains authoritative; typed Research Memory and generated `oncojevlab` Markdown/JSON are projections. Notebook edits never become scientific truth, and publication failure never rolls back evidence.
- New infrastructure does not retroactively restore missing historical bytes, prove old replayability or reinterpret historical decisions through a newer registry.
- Unknown licence, access, coverage, runtime support and reported cost remain unknown. Evaluation labels and diagnostic telemetry never enter scientific admission.
